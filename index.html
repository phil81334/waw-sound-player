About WaW Sound Player

      
An unofficial tool made for the World at War modding community.
Browse and play sounds stored in the game’s main IWD archives. No Modtools or running game required.

      
Plays individual PCM, Microsoft ADPCM and xWMA clips through Windows XAudio2. Loose files, FastFiles, sound aliases, editing and exporting are not included. Game files are never changed.

      
Independent of Treyarch, Activision and UGX. Built with JavaScript, Vite, Rust, Tauri and a small native Windows audio bridge. Open source under GPL-3.0; see ATTRIBUTION.md.

      
Created by phil81334.
